Projeto - Urban Routes – Design de Testes

1. Sobre o projeto: Projeto desenvolvido durante a formação em QA pela TripleTen, com foco no design de testes do formulário "Adicionar carteira de motorista" da funcionalidade de compartilhamento de carros do Urban Routes.

2. Objetivo: Analisar os requisitos e elaborar testes para validar os campos Nome, Sobrenome e Data de nascimento.

3. Atividades realizadas

- Análise dos requisitos da funcionalidade;
- Aplicação de classes de equivalência;
- Identificação de valores-limite;
- Definição de dados de teste para cenários positivos e negativos;
- Elaboração de casos de teste para o campo Nome.

4. Resultados

- Classes de equivalência para 3 campos;
- 9 casos de teste elaborados para o campo Nome;
- Cobertura de cenários válidos e inválidos.

5. Técnicas utilizadas

- Particionamento em classes de equivalência;
- Análise de valores-limite;
- Design de casos de teste.

6. Aprendizados: Prática em análise de requisitos, técnicas de design de testes e elaboração de documentação de QA.
